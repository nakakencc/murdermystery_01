# 制作ロードマップ

## 作る順番（この順だと矛盾が起きにくい）

1. **コンセプト** … 舞台・時代・トーン・惹きの一言 ✅
2. **事件の真相** … 誰が・誰を・どうやって・なぜ（＝解答） ✅
3. **タイムライン** … 事件当夜に何が起きたか（分単位） ✅
4. **キャラクター** … 6人分。役割 / 公開情報 / 秘密 / 目的 / 勝利条件 ✅
5. **調査カード** … 共通デッキ54枚・解答キー付き ✅
6. **進行ハンドブック** … GMレス用の読み上げ台本 　← いまここ
7. **テストプレイ ＆ 調整**
