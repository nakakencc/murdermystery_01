# はじめにお読みください（準備と進め方）

『十年目の毒杯』を卓上で遊ぶための一式です。

## フォルダの中身
- `ゲームブック_GM用.md` … 進行役が持つ全部入り（ルール／真相／人物／カード／得点）。**プレイヤーに渡さない。**
- `配布用/` … 印刷して配るもの。
  - `00_あらすじ（全員に配布）.md` … 全員に1枚ずつ。
  - `キャラ01〜06（本人のみ）.md` … **1人に1枚だけ**手渡す。他人のシートは見せない。

## 印刷リスト
1. あらすじ … 人数分。
2. キャラクターシート … 参加者に割り当てた1枚ずつ（計5〜6枚）。
3. 調査カード … `ゲームブック_GM用.md` の「調査カード一覧」の各カード本文を、1枚1カードで印刷。裏に**場所名のみ**記載。
4. 得点表 … 真相解説後に全員で見る用に1枚（またはゲームブックを開く）。

## 人数調整
- 6人：全キャラ使用。
- 5人：相馬を外し、カード19・24・49を抜く（詳細はゲームブックのカード一覧末尾）。

## 進行の流れ（要点）
導入 → キャラ読込 → 自己紹介 → 第1調査（密談並行）→ 議論① → 第2調査（密談並行）→ 議論② → 意見表明 → 投票 → 犯人処遇 → エンディング → 真相解説 → **採点**。

## 進行のコツ（テストプレイで判明）
- **カード22（20:40の目撃）は第2調査の開始時に山から抜き、全体へ公開**する（犯人の握り潰し対策・確定入手）。
- **白石の核心情報（薬の管理者＝桐生）は、カードが無くても本人が口頭で証言してよい**。
- 議論①が静かなら、進行役が呼び水を：「発見時の様子を白石さんから」「各自どこで何を？」。

## 勝敗
合計点が最も高い人が勝者。同点なら満点（＝難易度）が高い方。満点は 20/19/18/17/16/15 で全員異なるため必ず1人に決まる。
