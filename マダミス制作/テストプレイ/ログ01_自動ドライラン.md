# テストプレイ・ログ #01（自動ドライラン）

- 実施：自動シミュレーション（進行エンジン＝Claudeが6人全員を操作）
- 目的：解の収束性・バランス・進行の穴を洗い出す
- 構成：6人フル／共通デッキ54枚／想定ルール（無記名一斉・犯人名＋理由・同票は決選→逃亡・密談3人）
- 記法：🔍＝テストで気づいた課題（[重大]/[中]/[軽]）

---

## 0. 導入・自己紹介
- 進行役が導入文を読み上げ（※台本は未作成 → 🔍[中] 導入・宗一郎の宣言・第一発見の読み上げNPC台本が無い。ハンドブックで要作成）。
- 自己紹介：各自が公開プロフィールを口頭で。神谷が早くも宗一郎への不満を漏らし、相馬も招待理由に不快感。桐生は穏やかに振る舞う。
- この時点の空気：神谷・相馬が「感情的で怪しい」と見られる（＝ミスリード成立、狙い通り）。

## 1. 第1調査フェーズ（各自4枚）
主な入手（抜粋）：
- 白石：01毒物反応／30持病／08薬は主治医管理／45第一診断の矛盾 → 「発作death説」に疑問。ただし09（管理者＝桐生）はまだ未入手。
- 東條：34由紀転落／38写真／46恋人の噂／13宣言 → 過去に関心集中。
- 神谷：35(!)テラスで桐生目撃／16自分の口論／44クローズド → **いきなり核心35を引く**。
- 相馬：19自分の口論／24自分の粉飾／23美咲借金 → 自分と美咲の弱みばかり。
- 美咲：20自分の書斎前／31手帳／02すり替え跡 → 「殺人だ」と気づく。
- 桐生（犯人）：06毒の正体／12診療鞄ダミー／39洗浄剤 → **自分に不利な06を引いてしまい、握り潰す判断**。

🔍[中] 神谷が第1で35を引くと、過去の核心が早く出過ぎて緊張が緩む場合がある。一方で神谷は「自分が疑われている」ため証言の信用が低く、結果的にバランスは取れていた。→ 要観察（複数回まわす）。

## 2. 全体議論①
- 白石が「これは発作ではなく毒では」と提起（01・45）。場がざわつく。
- 神谷が「十年前、テラスに桐生がいた」と35を出すが、**神谷自身が容疑者扱い**され「話をそらすな」と一蹴される（狙い通りの機能）。
- 桐生は医師の権威で「01は保存状態の問題。発作で矛盾ない」と反論 → **犯人の防御が成立**。
- 現状の疑い：神谷＞相馬＞美咲。桐生はノーマーク。

🔍[良] 犯人の“医学的反論”が効いており、序盤で詰まない設計は機能。

## 3. 第2調査フェーズ（各自4枚）
- 白石：09管理者＝桐生／10「触れられるのは桐生だけ」→ **手段が桐生に直結**。だが白石は自分の隠蔽加担（41）露見を恐れ、出すのを渋る。
- 相馬：21・22（20:40桐生が薬包を持ち書斎へ）→ **決定的目撃**。しかし相馬は信用が低い。
- 美咲：48自分のアリバイ／51相続凍結 → 自分の潔白を示せる。
- 東條：40手紙／47日記 → 桐生と由紀の関係が物証で確定。
- 神谷：50自分のアリバイ／36由紀めまい。
- 桐生：05窓施錠／02すり替え → 不利カードを再び回収し沈黙。

🔍[中] 手段の柱が「21・22」の2枚に集中。両方を引くのが“信用の低い相馬”だと、正しい手掛かりが軽視されうる。→ 目撃系をもう1枚分散 or どれかを確定入手にする案。

## 4. 全体議論②
- 白石がついに09・10を開示（「本当は言いたくなかったが…」と41の加担も告白）。
- 東條が40手紙を提示、桐生と由紀の交際が確定。動機が浮上。
- 相馬の21・22が白石情報と噛み合い、「20:40に桐生が薬を持って書斎へ」が信憑性を得る。
- 桐生は反論を試みるが、手段（10）×機会（21/22）×動機（40）の三点が揃い、劣勢に。

🔍[良] “信用の低い者が握る正解”が、別ソース（白石・東條）と噛み合って初めて通る構造は良い。協力を促す。

## 5. 意見表明 → 投票（無記名一斉・犯人名＋理由）
- 白石・東條・美咲・神谷：桐生（理由：手段＋20:40＋手紙）
- 相馬：桐生
- 桐生：神谷（かく乱）
- 結果：桐生5票／神谷1票 → **桐生を正しく指摘**。

🔍[重大] 勝敗判定が未定義。「最多得票で確定」だと、序盤で神谷・相馬に票が割れていた場合、犯人が逃げ切る/無実が処刑される事故が起きうる。→ 判定ルールの明文化が必須（下記改善メモ）。

## 6. 犯人処遇 → アクション → エンディング → 解説
- 桐生が確定 → 追い詰められた桐生の独白（十年前の投薬ミスと隠蔽）。
- エンディング分岐：過去の真相（由紀の死）にも到達 → 完全解明エンド。
- 解説文の読み上げ（※未作成 → 🔍[中] エンディング／真相解説の台本が必要）。

- [重大] 勝敗判定ルールが未定義。最多得票か過半数か、同票時、無実処刑時の扱いを明文化する。
- [重大] 進行台本（導入・宣言・発見・各フェーズ合図・エンディング・解説）が未作成。GMレスでは必須。
- [中] 手段の柱「21・22（20:40目撃）」が2枚に集中し、握り手が“信用の低い相馬”。目撃をもう1枚追加 or 1枚を確定入手化。
- [中] 神谷の核心35が第1で出ると過去が早バレ気味。ただし神谷の低信用で相殺される。複数回まわして確認。

- [良] 犯人の医学的反論／低信用者が握る正解の相互補完／ミスリード配置は良好に機能。
