## 1. 基本仕様

| 項目 | 内容 |
|---|---|
| プレイ人数 | 5〜6人（可変） |
| 想定プレイ時間 | 本編120分 ＋ 感想戦（別枠） |
| GM | なし（GMレス進行） |
| 形式 | 対面 |
| 対象 | 初心者向け |

※ 人数可変のため、6人用シナリオを作り「1人抜ける場合の差し替えルート」を用意する方針で設計します（詳細は後工程）。

## 2. 進行フロー

```
導入
 ↓
キャラ読み込み
 ↓
キャラ自己紹介
 ↓
第1調査フェーズ（密談は並行）
 ↓
全体議論①
 ↓
第2調査フェーズ（密談は並行）
 ↓
全体議論②
 ↓
意見表明フェーズ
 ↓
投票
 ↓
犯人処遇フェーズ
 ↓
アクション
 ↓
エンディング
 ↓
真相解説
```

※ GMレスのため、各フェーズの合図・読み上げは「進行ハンドブック」を持ち回りで担当する形にします。

---

## 3. 情報公開ルール（確定）

| 行為 | 可否 |
|---|:---:|
| キャラクターシートを見せる | ✕ 不可 |
| 所持情報を口頭で共有する | ○ 可 |
| 証拠カードを他人に見せる | ○ 可 |
| 秘密を明かす | ○ 可 |
| 嘘の証言をする | ○ 可 |
| メタ読み（中の人の推測・確率論など） | ✕ 不可 |

### 情報の分類（設計時のタグ）
- 全員に最初から公開
- キャラ固有（本人だけが知る）
- 調査で入手
- 時間経過で公開
- 条件達成で公開
- プレイヤーが任意で公開
- 公開禁止

※「GMから読み上げる情報」はGMレスのため、**進行ハンドブックの読み上げ**に置き換えます。

## 4. 調査ルール（確定）

- 調査：**あり**
- 方式：**共通デッキ（全54枚）を場所ごとに伏せて配置**。プレイヤーは場所を選んでカードを引く
- デッキ：第1・第2調査で**共通の一つの山**。取ったカードは戻さない。**引き切らず余るカードが出てよい**（想定ドロー48枚／54枚中）
- 取得枚数：**1フェーズあたり 4枚／人**
- 読む権利：**調査した本人のみ**（本人が任意で口頭共有・提示可）
- カード種類（採用）：
  証拠 / 目撃情報 / 部屋情報 / 被害者情報 / 凶器情報 / 時系列情報 / ミスリード情報 / その他
- 不採用：GMに質問する（GM不在のため）

---

## 5. 密談ルール（確定）

- 密談：**あり**（**密談フェーズのみ**。常時密談は不可）
- 密談時間：フェーズ内は自由
- 密談回数：フェーズ内は自由
- 密談中に証拠を見せる：**可**
- 密談内容を嘘で報告する：**可**
- 密談できる人数：**未決定**（1対1のみ ／ 最大3人）

---

## 6. 投票・推理ルール（未決定・要選定）

- 投票対象（候補）：犯人 / 黒幕 / 共犯者 / 特定の真相
- 投票方式（候補）：一斉投票 / 記名 / 無記名 / 個別提出
- 推理提出レベル（候補）：犯人名のみ / ＋理由 / ＋犯行方法 / ＋動機
- 同票時の処理（候補）：決選投票 / 犯人逃亡 / エンディング分岐

※ 初心者向けなので、後工程で「シンプルかつ盛り上がる」組み合わせを提案します。
